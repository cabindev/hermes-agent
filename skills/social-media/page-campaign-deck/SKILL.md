# Page Campaign Deck

สรุปแคมเปญของเพจให้เป็นภาพเดียวที่คนดูรู้เรื่อง ตั้งแต่ดึงข้อมูลดิบ จนได้เด็คสไลด์
ที่ส่งต่อเข้า Canva ได้ ทำครั้งแรกกับชุด **เยาวชนสุขเกินร้อย / งานร้อยเอ็ด** ของเพจ CivicSpace

อ่านอย่างเดียว ไม่โพสต์ ไม่ตอบคอมเมนต์ ไม่แก้อะไรบนเพจ
คู่กับ `facebook-page-monitor` ซึ่งเป็นตัวรายงานความเคลื่อนไหวรายสัปดาห์ สกิลนี้คือตัวทำงานออกแบบ

## When to Use

- "รวมงานเรื่อง X ที่เคยทำมาให้หน่อย" / "ทำสไลด์สรุปแคมเปญ Y"
- อยากเห็นภาพรวมว่าเพจเล่าเรื่องอะไรไปแล้วบ้าง ชิ้นไหนแรง ชิ้นไหนเงียบ
- ต้องส่งงานให้ทีมแก้ต่อใน Canva

## ขั้นตอน

### 1 ดึงข้อมูล

```bash
python3 campaign_pull.py --keyword ร้อยเอ็ด --since 365d --out out/ --thumbs
```

ได้ `out/campaign.json` (ยอดถูกใจ คอมเมนต์ แชร์ ต่อชิ้น พร้อมลิงก์และวันที่แบบไทย)
และ `out/img/NN.jpg` คือภาพปกจริงของแต่ละชิ้น ย่อไว้ราว 15-35 KB พร้อมฝังในงานออกแบบ

credential อ่านตามลำดับ env → `.env` ของ Hermes เหมือน `facebook-page-monitor`
ติดปัญหาสิทธิ์เมื่อไหร่ให้ยิง `page_report.py --check` ของสกิลนั้นดูก่อน

### 2 เทียบจำนวนกับที่ Facebook นับ

ก่อนเชื่อตัวเลข ให้ผู้ใช้เปิดหน้าหมวดเนื้อหาใน Facebook แล้วเทียบจำนวนรวม
รอบร้อยเอ็ดได้ 25 ชิ้นเท่ากันพอดี แต่ Facebook แยกเป็นโพสต์ 4 วิดีโอ 21 ส่วน API แยกเป็น
วิดีโอ 20 อัลบั้มภาพ 5 ต่างกันหนึ่งชิ้นเพราะนิยามชนิดไม่ตรงกัน **ให้รายงานส่วนต่างตรง ๆ อย่ากลบ**

### 3 จัดกลุ่มเนื้อหา

อ่าน `message` ของทุกชิ้นแล้วตั้งธีมเอง 4-5 กลุ่ม ตั้งชื่อกลุ่มด้วยภาษาที่ผู้ใช้ใช้จริง
**การจัดกลุ่มเป็นการตีความ ไม่ใช่หมวดจาก Facebook** ต้องเขียนกำกับไว้ในงานทุกครั้ง
ชิ้นที่ยืมไปโชว์ในกลุ่มอื่นให้ตีกรอบเส้นประ แล้วบอกว่ายอดของมันนับอยู่กลุ่มไหน จะได้ไม่นับซ้ำ

### 4 ประกอบเด็ค

ใช้สกิล `design` (Claude Design canvas) หนึ่งอาร์ตบอร์ดต่อหนึ่งสไลด์ ขนาด **1920×1080**
ซึ่งตรงกับเทมเพลต Presentation ของ Canva พอดี โครงที่ใช้ได้ผลมาแล้ว

| แผ่น | เนื้อหา |
|---|---|
| 1 | วงโคจร — เส้นเรื่องหลักอยู่วงกลาง ชุดที่ติดแฮชแท็กเป็นวงใน งานอื่นเป็นวงนอก |
| 2 | เส้นทาง — ไทม์ไลน์สองแถวที่ไหลไปจบที่วงปลายทาง |
| 3 | นิเวศจักรวาล — ธีมทั้งหมดเรียงตามแรงที่ได้กลับมา |
| 4 | เสียงของคน — คำพูดจริงจากคลิป |
| 5 | เนื้อหาที่ได้รับความสนใจ — ตัวเลขรวมและห้าอันดับแรก |
| 6 | บทสรุป — สิ่งที่ตัวเลขยืนยันได้ แยกจากเป้าหมายที่ยังไม่ได้วัด |

**ระบบภาพ** พื้นหลัง `#0e1420` แผง `#19202f` เส้น `#2b3342` ตัวอักษร `#f2eee6` / `#a9a49a` / `#767168`
ทอง `#bb881a` (แท่งกราฟ) `#e0ae57` (ป้ายและเส้นเน้น) เขียว `#00ab92` (ชิ้นที่แรงที่สุด)
คู่ทอง-เขียวผ่านการตรวจ contrast และตาบอดสีมาแล้ว อย่าเปลี่ยนโดยไม่ตรวจใหม่

**ฟอนต์ FC Vision** อยู่ที่ `~/Library/Fonts/FCVision-*.otf` ฝังเป็น data URI ในทุกอาร์ตบอร์ด
ใช้สามน้ำหนัก Regular 400 / Medium 500 / Bold 700 ไฟล์ละ ~44 KB ห้ามลิงก์ออกนอกหน้า
เพราะกรอบของอาร์ติแฟกต์ต่อเน็ตออกไม่ได้ ยกเว้น Google Fonts

**ขนาดวงกลม** ห้าอันดับแรกขยายไล่ระดับ ×1.75 ×1.50 ×1.32 ×1.18 ×1.10 ที่เหลือคงขนาดเดิม
อย่าสเกลตามยอดจริง เพราะอันดับหนึ่งมักแรงกว่าอันดับห้าสิบเท่า วงเล็กจะหายไปหมด

### 5 ออกไฟล์ให้ Canva

**Canva แก้ข้อความไม่ได้ถ้าส่ง PDF** เพราะ PDF ที่ออกจากอาร์ติแฟกต์เป็นภาพแรสเตอร์
ต้องสร้าง **PPTX** ด้วย `python-pptx` แล้วผู้ใช้อัปเองที่ canva.com → Upload

```bash
python3 -m venv .venv && .venv/bin/pip install python-pptx Pillow
python3 circle_crop.py out/img out/circ          # PPTX วางรูปเป็นสี่เหลี่ยม ต้องครอปวงกลมมาก่อน
```

ค่าคงที่ที่ใช้ตอนวาดสไลด์ PPTX

- สไลด์ 1920×1080 px = `prs.slide_width = Emu(1920 * 6350)` (1 px = 6350 EMU)
- ขนาดตัวอักษร `pt = px / 2` เช่นหัวเรื่อง 64 px = 32 pt
- ตั้งชื่อฟอนต์เป็น `FC Vision` ได้ แต่ Canva ไม่มีในคลัง จะสลับเป็นฟอนต์ใกล้เคียงเสมอ บอกผู้ใช้ไว้ก่อน
- ตรวจงานด้วย `qlmanage -t -s 1400 -o preview file.pptx` แล้วเปิดรูปดู ตัวอักษรไทยชนกันบ่อยที่ป้ายใต้ตัวเลขใหญ่

**ตัวเชื่อม Canva ในเซสชันรับเฉพาะ URL สาธารณะ** ห้ามเอาไฟล์ของผู้ใช้ไปฝากโฮสต์สาธารณะเพื่อสร้างลิงก์
ให้ผู้ใช้อัปไฟล์เองเสมอ

## Pitfalls

- **ยอดขยับระหว่างการดึงสองครั้ง** โพสต์ใหม่ยังวิ่งอยู่ ให้เขียนวันที่ดึงข้อมูลกำกับในงานเสมอ
- **Graph เก็บย้อนหลังราว 12 เดือน** ขอไกลกว่านั้นได้ไม่ครบ
- **คำค้นจับเฉพาะ `message`** ชื่อเล่นที่พูดในคลิปแต่ไม่ได้พิมพ์ในแคปชันจะหาไม่เจอ
  เจอมาแล้วกับ "น้องฟลุ๊ก" ซึ่งแคปชันเขียนว่า ธีระเดช เกณท์สระคู ถ้าหาไม่เจอให้ถามผู้ใช้ อย่าเดา
- **แคปชันไม่ใช่คำพูดเสมอไป** ถ้าเป็นคำที่เพจเล่าถึงคนนั้น อย่าใส่อัญประกาศ ให้ติดป้ายว่าเรื่องเล่าจากเพจ
- **data access ของ token หมดอายุ 18 พ.ย. 2026** ดู `facebook-page-monitor` เรื่องการต่ออายุ
- **อาร์ติแฟกต์มีเพดาน 16 MB** ภาพ 25 ใบที่ย่อแล้วกับฟอนต์สามน้ำหนักรวมราว 4 MB ยังเหลือที่
- **ถ้าผู้ใช้แก้งานในเอดิเตอร์** ต้องอ่านเวอร์ชันล่าสุดกลับมาก่อนเผยแพร่ทับเสมอ ไม่งั้นงานเขาหาย

## ประเด็นที่ทำไว้แล้ว

สกิลนี้คือกลไก ส่วนความรู้ของแต่ละประเด็นอยู่แยกกันคนละสกิล

- `civicspace/roiet-youth` — เยาวชนสุขเกินร้อย งานร้อยเอ็ด ธีมจักรวาลกลางคืน
- `civicspace/funeral-norms` — เปลี่ยนค่านิยมงานศพ ธีมกระดาษพื้นขาว

**เพิ่มประเด็นใหม่** สร้าง `skills/civicspace/<ชื่อประเด็น>/SKILL.md` แล้วเขียนหกหัวข้อนี้
เป้าหมายของงาน · คำค้นและจำนวนที่ได้ ณ วันไหน · ธีมที่จัดไว้พร้อมยอด ·
เสียงที่ใช้ได้พร้อมที่มา · ข้อค้นพบที่ใช้ต่อได้ · ระบบภาพและโลโก้ของประเด็นนั้น
อย่าก๊อบสคริปต์ไปไว้ในสกิลประเด็น ให้เรียกจากที่นี่ที่เดียว

# ประเด็น เยาวชนสุขเกินร้อย · งานร้อยเอ็ด

ความรู้เฉพาะของประเด็นนี้ กลไกอยู่ที่สกิล `page-campaign-deck`

## เป้าหมายของงาน

เล่าว่าเมืองร้อยเอ็ดกำลังเดินไปทางไหน ผ่านวัฒนธรรม พื้นที่สาธารณะ และเสียงของเยาวชน
โดยมีชุด **#เยาวชนสุขเกินร้อย** เป็นแกนกลาง

## ดึงข้อมูล

```bash
python3 ../../social-media/page-campaign-deck/campaign_pull.py \
  --keyword ร้อยเอ็ด --since 365d --out out/ --thumbs
```

ณ 9 ก.ย. 2026 ได้ **25 ชิ้น · 14 พ.ค. – 28 ส.ค. 2026 · 107 วัน · 39,573 การมีส่วนร่วม**
Facebook นับหมวดนี้ไว้ 25 ชิ้นเท่ากันพอดี แต่แยกเป็นโพสต์ 4 วิดีโอ 21
ส่วน API แยกเป็นวิดีโอ 20 อัลบั้มภาพ 5 ต่างกันหนึ่งชิ้น **ให้รายงานส่วนต่างตรง ๆ**

ชุดที่ติดแฮชแท็ก `#เยาวชนสุขเกินร้อย` จริง ๆ มีแค่ **8 ชิ้น 6,170 การมีส่วนร่วม**
คิดเป็น 15.6% ของทั้งชุด ใช้เป็นวงในของแผนที่จักรวาล ที่เหลือ 17 ชิ้นเป็นวงนอก
